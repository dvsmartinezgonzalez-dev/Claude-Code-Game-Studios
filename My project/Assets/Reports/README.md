# Cleanup Reports

Reports generated by the editor tools in `Assets/Editor/CleanupTools/`.
These must be run from inside the Unity Editor (they cannot run headless from CLI).

## Workflow (run inside Unity)

1. `Cleanup > Generate Unused Asset Report`
   → `Assets/Reports/unused_candidates_before.csv`
   Lists assets not referenced by any enabled build scene or prefab.
   **Review manually** — the Resources.Load heuristic is approximate; never delete
   anything under `Assets/Resources/` without confirming it is not loaded by name.

2. `Cleanup > Optimize Large Textures and Audio (Conservative)`
   → `Assets/Reports/texture_compression_report.csv`
   Reduces maxTextureSize + enables crunch compression on textures > 200 KB.
   **Destructive reimport** — verify visually after running. Revert with
   `git checkout -- "My project/Assets"` if results are unacceptable.
